# Analysis Scope

## Project Dataset

This project uses CMS Program Statistics Medicare Inpatient Hospital data to analyze Medicare inpatient hospital utilization and program payments.

The analysis uses multiple years of publicly available CMS data to examine trends and differences across demographic, geographic, and hospital characteristics.

## Selected Tables

The project focuses primarily on the following Medicare Inpatient Hospital tables:

### Table 1 — Inpatient Hospital Trends
Used to analyze changes in inpatient hospital utilization, program payments, and cost sharing over time.

### Table 2 — Demographic Characteristics
Used to examine inpatient hospital utilization and payment measures across demographic and Medicare enrollment characteristics.

### Table 3 — Area of Residence
Used to analyze geographic differences in Medicare inpatient hospital utilization and payments.

### Table 4 — Hospital Type
Used to compare utilization and payment measures across different inpatient hospital types.

### Table 9 — Hospital Characteristics
Used to analyze IPPS short-stay hospitals by characteristics such as location, bed size, medical school affiliation, and type of control.

## Tables Not Included in the Initial Analysis

Tables 5–8 are specific to short-stay hospitals paid under the Inpatient Prospective Payment System (IPPS). These tables may be incorporated into later analysis if additional detail is needed.

Table 10 focuses on special-category hospitals and is outside the initial scope of this project.

## Analysis Period

The project uses CMS Medicare Inpatient Hospital datasets covering 2017 through 2023 where comparable measures are available.

Because some CMS tables contain historical trend periods within individual annual files, duplicate reporting periods will be identified and handled during data preparation.

## Data Quality Considerations

CMS suppresses certain small beneficiary counts to protect privacy. Suppressed values are not interpreted as zero and will be handled separately during data preparation.

Differences in table structure, column names, and available measures across reporting years will be evaluated before annual datasets are combined.

## Planned Analysis

The project will examine:

- Inpatient hospital utilization trends
- Medicare program payment trends
- Geographic variation
- Demographic differences
- Differences by hospital type
- Differences by hospital characteristics
- Relationships between utilization and program payments
- Year-over-year changes in selected measures
