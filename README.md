# Medicare Inpatient Hospital Analytics

## Project Overview

This project analyzes real Medicare inpatient hospital data published by the Centers for Medicare & Medicaid Services (CMS).

The project will examine hospital utilization, Medicare program payments, and trends using SQL, Python, and Tableau.

## Data Source

Centers for Medicare & Medicaid Services (CMS)  
CMS Program Statistics — Medicare Inpatient Hospital

## Tools & Technologies

- SQL
- Python
- Pandas
- Excel
- Tableau Public
- Git/GitHub

## Project Workflow

1. Collect CMS Medicare Inpatient Hospital data
2. Review CMS methodology and data definitions
3. Validate and clean the data
4. Combine relevant annual datasets
5. Perform exploratory data analysis
6. Analyze utilization and payment trends
7. Develop healthcare KPIs
8. Create an interactive Tableau dashboard
9. Document findings and business insights
